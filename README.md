# 🏦 Secure Bank – Banking Management System

A web-based **Banking Management System** developed using **Python and Flask** as part of my Python Development Internship at TEN.

The application provides essential banking operations through a user-friendly interface, with separate functionalities for **customers and administrators**.

## 🚀 Features

### 👤 Customer Module

* User registration and login
* Secure authentication
* Bank account creation and management
* Deposit and withdrawal
* Account-to-account money transfer
* Transaction history
* Account balance management

### 🔐 Admin Module

* Admin authentication
* Manage customer accounts
* Monitor banking activities
* View transaction-related information

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/secure-bank-management-system.git
```

### 2. Open the project folder

```bash
cd secure-bank-management-system
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Open the application in your browser at:

```text
http://127.0.0.1:5000/
```
